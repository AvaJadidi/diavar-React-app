# divar react-app

divar react-app یک وبسایت است که به کاربران این امکان را می‌دهد تا آگهی فروش هر نوع وسیله‌ای را با دسته‌بندی خاص خود قرار دهند.

## ویژگی‌ها

- پروژه با استفاده از **React** نوشته شده است.
- کاملاً **ماژولار** و دارای کامپوننت‌های مختلف.
- دارای **صفحه ادمین** برای اضافه، ویرایش و حذف دسته‌بندی‌ها.
- صفحه **ثبت نام** کاربر با شماره تلفن و صفحه **ورود و خروج**.
- صفحه **داشبورد** برای اضافه کردن آگهی‌های فروش و ویرایش و حذف آن‌ها.
- قابلیت **فیلتر دسته‌بندی محصولات** و **جستجو** محصول.

## نصب و راه‌اندازی

این پروژه دارای **API** و بک‌اند است که در گیت‌هاب با آدرس [divarAPI](https://github.com/username/divarAPI) قرار گرفته است. پروژه تمام داده‌های خود را از این فایل بک‌اند دریافت می‌کند.

برای نصب و راه‌اندازی پروژه، مراحل زیر را دنبال کنید:

1. این مخزن را کلون کنید:
   bash
   git clone https://github.com/avajadidi/divar-react-app.git
   cd divar-react-app
   
2. وابستگی‌ها را نصب کنید:
   bash
   npm install
   
3. پروژه را اجرا کنید:
   bash
   npm start
   
## استفاده

پس از راه‌اندازی پروژه، می‌توانید به آدرس http://localhost:3000 مراجعه کنید تا از امکانات وبسایت استفاده کنید.
